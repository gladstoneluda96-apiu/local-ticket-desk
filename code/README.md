# 工单记录小工具产品设计包

本目录基于 `工单记录小工具_产品需求文档_v1.2.pdf` 整理产品设计与静态交互原型。

## 文件说明

- `PRODUCT_DESIGN.md`：产品设计说明书，包含定位、用户、MVP 范围、页面设计与关键规则。
- `INFORMATION_ARCHITECTURE.md`：信息架构、导航结构、字段分组与页面布局。
- `USER_FLOWS.md`：核心用户流程、异常流程与状态流转。
- `DATA_AND_RULES.md`：数据模型、识别规则、状态规则、安全与导出规则补充。
- `index.html`：可打开的静态高保真原型。
- `styles.css`：原型样式。
- `app.js`：原型交互逻辑。

## 打开原型

推荐用本地服务打开，这样联网识别不会被浏览器 CORS 卡住：

```bash
node server.js
```

然后访问 `http://127.0.0.1:4173`。原型支持：

- 工单搜索与状态筛选
- 工单详情切换
- 状态切换与操作日志追加
- 输入反馈文本、粘贴/选择/拖拽截图并创建工单
- 识别方式两种：本地 Ollama（免费离线）或联网识别（默认智谱 GLM-4V-Flash，可切换其他厂商）
- 截图文字提取：可用 macOS 系统 OCR（毫秒级、离线）先转文字再结构化
- 在详情页手工编辑工单字段，并自动记录操作日志
- 导出当前筛选结果为 Excel 或 CSV 本地表格
- 设置弹窗与导出弹窗
- 日间 / 夜间双主题（白 + 蓝、黑 + 蓝），支持手动切换并记住偏好
- 识别连接失败时保留输入文字与截图，可重试或跳过识别直接创建草稿

## 产品一句话

一款默认离线运行的桌面端工单记录工具，把 IM 里的碎片化反馈快速转成可追踪、可导出、可审计的结构化工单。

## 识别方案

设置页“AI 识别 - 识别方式”提供两个顶层方案：

### 1. 本地 Ollama（免费离线）

- Base URL: `http://127.0.0.1:11434/v1`
- 模型: `qwen3-vl:4b`（本机已下载；内存充足可换 `qwen3-vl:8b`）
- 无需 API Key，完全离线，数据不出本机。首次使用先打开 Ollama 并拉取模型：

```bash
ollama pull qwen3-vl:4b
```

### 2. 联网识别（默认智谱 GLM-4V-Flash 免费）

- Base URL: `https://open.bigmodel.cn/api/paas/v4`
- 模型名称: `glm-4v-flash`（免费视觉模型，可直接理解截图）
- 可选模型: `glm-4.6v-flash`、`glm-4.1v-thinking-flash`

联网方案保留厂商切换：DeepSeek V4、通义千问 Qwen VL、Kimi、智谱 GLM-OCR、OpenAI 兼容接口均可随时切换。

说明：

- GLM-4V-Flash 是智谱开放平台（bigmodel.cn）的免费图片理解模型，创建工单时直接读取截图与文本，无需先做 OCR。
- 开启联网识别后，仅在创建工单时发送当前输入文字与本次截图，不做后台上传；数据脱敏默认开启。
- API Key 在智谱开放平台创建，原型暂存在当前浏览器本地，正式版应接系统密钥库。
- 识别连接失败（网络原因或 Ollama 未启动）时，输入文字与截图会保留在输入框，可重试，或点击“跳过识别，直接创建草稿”。

## 主题

- 日间模式：白底 + 蓝主色；夜间模式：黑底 + 蓝主色。
- 首次打开跟随系统外观，右上角太阳/月亮按钮可手动切换，偏好会保存在本地。

## 界面布局

以工单列表为主视图，详情放在右侧抽屉，底部是常驻录入条：

- 状态筛选做成横向胶囊条，和排序一起放在列表头部，列表区获得更大空间
- 列表是自适应网格：抽屉展开时约三列，收起后铺满整行
- 卡片按「状态色条 + 问题概括 + 弱化元信息」分层，优先级用色点表达
- 详情区分「已识别 / 待补充」两种字段状态，待补充字段用虚线高亮
- 字段修改改为显式保存：改完点「保存修改」才落库，可一键放弃，避免失焦误存
- 新建工单会高亮并自动滚动到位，同时自动展开详情

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Cmd + K` | 聚焦底部录入框 |
| `J` / `K` | 下一条 / 上一条工单 |
| `Cmd + Enter` | 提交创建工单 |
| `Esc` | 关闭弹窗，或收起详情面板（有未保存修改时先放弃修改） |

## macOS 系统 OCR

截图文字提取默认是「自动」：本地识别时，先用 macOS 自带的 Vision 框架（与「实况文本」同源）离线提取截图文字，再交给模型做字段结构化。

- 单张截图约 200 到 300 毫秒，完全离线，中文识别质量高
- 效果：同一张截图的完整建单耗时从 44 秒降到 8 秒左右
- 设置里可选：自动（本地识别时启用）/ 始终启用 / 关闭（关闭则直接让模型看图）
- 提取出的文字会写进工单描述；识别失败时点「跳过识别，直接创建草稿」也会带上这些文字
- 独立接口 `POST /api/ocr`（传 `{ images: [dataURL] }`），只提取文字、不依赖任何模型
- 工具源码在 `tools/ocr.swift`，首次使用会自动编译成 `tools/ocr`（需要命令行工具链；已装 Command Line Tools 即可）
