# 工单记录小工具产品设计说明书

## 1. 产品定位

工单记录小工具是一款面向产品、客服、运营、技术支持与研发协作角色的本地桌面工具。它解决的是“反馈已经来了，但没有被稳定记录、追踪和复盘”的问题。

产品不替代 Jira、TAPD、禅道等正式研发协同系统，而是作为反馈进入正式系统前后的轻量记录层：

- 将 IM 中的文本、截图、混合消息快速转成结构化工单。
- 用本地工单号保证每条反馈都有唯一追踪入口。
- 允许用户补充外部工单号，承接正式系统流转。
- 默认离线运行，只有用户主动开启时才调用外部 LLM。

## 2. 用户与场景

### 目标用户

- 产品经理：沉淀需求反馈、复盘问题分布、准备周报。
- 客服/运营：记录客户问题、追踪处理进展、统一反馈口径。
- 技术支持：把聊天中的问题整理成可交接的处理单。
- 研发：查看问题背景、外部工单号、状态与处理备注。

### 核心场景

用户从企业微信、飞书、钉钉等 IM 中收到反馈，将文字或截图粘贴到工具底部输入框。工具完成本地 OCR 与字段识别后生成工单。用户核对字段，补充外部工单号和处理备注，并在处理过程中更新状态，最终归档销号。

## 3. 产品原则

- 离线优先：本地解析、本地存储、本地导出，云端能力默认关闭。
- 草稿可信：AI 识别结果只作为草稿，所有字段都允许人工校正。
- 双轨追溯：本地工单号负责工具内唯一标识，外部工单号负责关联 Jira/TAPD/禅道等系统。
- 少打扰：列表、详情、录入在一个主界面内完成，避免频繁切页。
- 可审计：状态变化、AI 识别来源、云端兜底调用都进入操作日志。

## 4. MVP 范围

### 必须做

- 桌面端主界面：侧边状态导航、工单列表、详情面板、底部输入框。
- 文本输入与图片附件入口。
- 本地工单号生成：`LOC-{UUID v4}`，不可编辑。
- 工单详情字段编辑：反馈人、问题概括、问题描述、问题背景、操作菜单、反馈时间。
- 人工字段：外部工单号、处理人、处理备注、优先级。
- 状态流转：待处理、已处理、待验证、待反馈。
- 搜索、筛选、排序。
- CSV 与 Excel 导出。
- 设置页：联网 LLM 兜底配置、脱敏、阈值、超时。
- 操作日志。

### MVP 可降级

- OCR 可先接入 Tesseract 或 PaddleOCR 单机模型，识别质量在后续迭代优化。
- 本地 NLP 可先采用规则引擎 + 轻量关键词抽取，再逐步替换为本地小模型。
- Excel 导出可先用 `.xlsx` 基础表格，不需要复杂样式。

### 暂不做

- 多人实时协作。
- 远程服务端同步。
- 外部工单系统 API 自动校验或自动创建。
- 移动端。

## 5. 页面设计

### 5.1 主工作台

主工作台采用三栏加底部输入结构：

- 左侧：状态导航与统计，帮助用户快速切换工作队列。
- 中部：工单列表，承担筛选、搜索、批量导出前的浏览。
- 右侧：工单详情，承担字段核对、状态维护、日志查看。
- 底部：聊天式输入框，承担新工单录入。

主界面应优先保证“录入后立即核对”和“查看列表后快速维护”两个动作流畅。

### 5.2 工单列表

列表卡片展示信息优先级：

1. 状态色条与短码本地工单号。
2. 问题概括。
3. 反馈人、反馈时间、外部工单号。
4. 优先级与识别来源。

交互规则：

- 点击卡片后右侧详情同步切换。
- 搜索支持本地工单号完整值、短码、外部工单号、反馈人、问题概括。
- 状态筛选与搜索条件叠加生效。
- 短码悬停展示完整本地工单号。

### 5.3 工单详情

详情页顶部展示完整本地工单号与复制按钮。其下方是状态分段控件、核心识别字段、人工维护字段、附件、操作日志。

字段组织：

- 主标识区：本地工单号、状态、创建时间、识别来源。
- AI 草稿区：反馈人、问题概括、问题描述、问题背景、操作菜单、反馈时间。
- 人工维护区：外部工单号、处理人、优先级、处理备注。
- 证据区：截图附件与 OCR 文本。
- 审计区：操作日志。

### 5.4 新建工单输入区

输入框采用聊天式体验：

- 支持直接输入或粘贴文本。
- 支持图片拖拽、粘贴、缩略图预览与删除。
- `Cmd/Ctrl + Enter` 提交。
- 解析过程中显示进度：读取输入、OCR、字段抽取、置信度评估、写入数据库。
- 低置信字段在详情页以“待补充”提示。

### 5.5 设置页

设置页采用 iOS 设置 App 的分组列表样式：

- AI 识别：联网兜底开关、模式、提供商、Base URL、模型名、阈值、超时、脱敏。
- 数据与导出：默认导出格式、附件存储位置、数据目录。
- 安全：API Key 管理、首次开启提示、审计开关。

## 6. 关键体验细节

- 新建成功后自动选中新工单，并打开详情页。
- AI 识别低置信字段不强行填值，避免把错误信息包装成确定结果。
- 云端兜底失败时保留本地结果，并在日志写入失败原因。
- 外部工单号支持一键复制，但不做联网校验。
- 导出基于当前筛选结果，导出前显示数量。
- 删除或归档销号需二次确认。

## 7. 设计风格

视觉采用 iOS 17 / iPadOS 风格：

- 背景：`#F2F2F7`
- 主色：`#007AFF`
- 成功：`#34C759`
- 警示：`#FF9500`
- 信息：`#5AC8FA`
- 危险：`#FF3B30`
- 圆角：主体面板 16px，按钮 12px，列表卡片 14px。
- 顶部栏与侧边栏使用半透明毛玻璃效果。
- 动效控制在 200ms 到 300ms，强调轻量与可预期。

## 8. 待确认问题

- 桌面端首发是否选择 Tauri，还是因 OCR/模型生态优先选择 Electron？
- 本地 OCR 模型是否允许随安装包内置，安装包体积上限是多少？
- 附件是否需要设置单条工单数量和文件大小限制？
- 外部工单号是否只保存文本，还是需要支持 URL 模板跳转？
- 数据目录是否需要支持用户自定义迁移？
