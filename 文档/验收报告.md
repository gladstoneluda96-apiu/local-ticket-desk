## 5. 遗留问题与限制

以下事项不影响本期验收，列为后续改进方向：

| 编号 | 事项 | 说明 |
| --- | --- | --- |
| E-01 | API Key 存储位置 | 当前存于浏览器本地，正式版应迁入系统密钥库 |
| E-02 | 日志为文本形式 | 未结构化存储旧值 / 新值，统计能力有限 |
| E-03 | 附件未保存 OCR 文本 | 无法对截图内容做全文检索 |
| E-04 | 未做状态机约束 | 允许状态跳跃，仅通过日志留痕 |
| E-05 | 搜索为内存过滤 | 数据量大幅增长后需改为数据库查询 |
| E-06 | 系统 OCR 限 macOS | 跨平台需替换 OCR 方案 |
| E-07 | 单机单用户 | 无多人协作与多端同步 |
| E-08 | 无自动化测试套件入库 | 当前验证依赖临时脚本与浏览器自动化，建议后续沉淀为可重复执行的用例 |

4. 遗留问题均已记录在案，属于增强项而非缺陷，不影响当前单机使用。
